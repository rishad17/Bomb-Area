# 💣 Bomberman Clone

A modern twist on the classic **Bomberman** arcade game! Drop bombs, blow up walls, and outsmart your enemies in this explosive action-puzzle experience.
Built with ❤️ for retro gaming fans.

![Gameplay Screenshot](./screenshots/gameplay.png) <!-- Replace with your actual image path -->

---

## 🚀 Features

* 🎮 Classic grid-based Bomberman gameplay
* 💥 Explosive bomb mechanics with chain reactions
* 🤖 Smart AI opponents (or play solo!)
* 🧱 Breakable and unbreakable walls
* 🔥 Power-ups: extra bombs, fire range, speed boost
* 🎵 Retro-style pixel art and sound effects
* 🕹️ Controller and keyboard support
* 🧑‍🤝‍🧑 Multiplayer (Local or Online) *(optional)*

---

## 🕹️ Controls

| Action     | Key (default)     |
| ---------- | ----------------- |
| Move       | Arrow Keys / WASD |
| Place Bomb | Spacebar          |
| Pause      | Esc               |
